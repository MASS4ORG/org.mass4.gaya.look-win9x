# Windows 95/98 look

Beveled gray controls, sunken fields and navy selections for the Gaya Studio, with the Windows Classic color theme.

Licensed under MIT. See `package.json` for version and engine compatibility.

## Install

```sh
turian-cli brick add org.mass4.gaya.look-win9x
```

Or enable `org.mass4.gaya.look-win9x` from the Bricks panel.

## Bricks v2

This look is already consumable and declares `bake: none`, so it has no redundant twin. Its test tooling lives under the opaque `Brick~/Tests` role. Pack with `turian-cli brick pack . --out .bricks`.
